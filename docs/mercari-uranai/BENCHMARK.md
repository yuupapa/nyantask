## 2. メルカリ成功出品者に共通する型(調査結果)

| 要素 | 型 |
|---|---|
| サムネ | ネイビー×ゴールド、紫グラデ等の神秘系配色+タロット・月・星のモチーフ。Canvaで統一デザイン。複数枚構成(メイン/内容説明/鑑定書イメージ/世界観) |
| タイトル | 「鑑定書」「鑑定書送付」「鑑定書付き」を必ず入れる(有形物の明示)+「24時間以内」等の即応性 |
| 価格帯 | 入口300〜1,000円は競合過多で価格競争。稼いでいる層は中単価(1,000〜10,000円)に幅を持たせている |
| 納品物 | A4カラー8〜15ページの鑑定書+封筒。手書きのサンキューカード同梱で評価を上げる運用 |
| プロフィール | 占い専門アカウントとして世界観統一(不用品出品と混ぜない)。冒頭に挨拶・感謝 |
| ラダー | 「お試し価格」出品と「Aコース/Bコース」等のコース分けで二段〜三段の価格帯を並行出品 |

**観察された注意点**:「鑑定書つきならセーフ」という通説に対し、実際にアカウント停止に至った報告も複数ある(調査記事が一致して指摘)。ベンチマークの量販型(500円均一シリーズ等)は事業的利用と見なされるリスクが高い運用であり、**規模は参考にせず、型だけを参考にする**。
