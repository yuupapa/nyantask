## 4. 方針(確定案)

**結論:「恋愛×タロット専門・誠実路線・即応性で差別化」で行きます。ベンチマークはココナラのNnatty型(入口二段+誠実路線)を主参照、メルカリの「お試し価格→コース分け」型を0→1に適用します。**

| 項目 | 方針 | 根拠 |
|---|---|---|
| ジャンル | **恋愛×タロット専門**(入口:彼の気持ち/アップセル:復縁・詳細鑑定)。金運・総合は当面出さない | 市場の60〜70%が恋愛系(Wiki比率)。専門特化はベンチマーク共通の型 |
| 価格(0→1メルカリ) | 入口500円(レビュー3件まで)→800円/詳細鑑定3,000円 | `ROADMAP-0-1.md` §5.1の原価と両立 |
| 価格(Stage 2ココナラ) | Nnatty型の入口二段:お試し500円/本鑑定1,000円→レビュー5件で1,000/1,500円へ | ベンチマーク実証の型 |
| 鑑定書の設計 | 入口A4 1〜2枚/詳細A4 3〜4枚。**ページ数では戦わない**(8〜15ページ勢とは別路線)。差別化は「24〜48h納品の速さ」+「相談内容に固有の一文」 | 週5時間の時間予算(1件30分)を守るため。ボリューム競争は時間コスト構造的に不利 |
| 世界観 | 神秘系だが穏やかなトーン:ネイビー×ゴールド基調+月・タロットモチーフ、Canvaで統一。**誠実路線**(良い結果も悪い結果も丁寧に、必ず前向きな一歩で締める) | サムネの定番配色+Nnattyの誠実路線はNG表現回避(断定・不安煽りの禁止)と構造的に相性が良い |
| AI表記 | タイトルには入れない。説明文で「AIを補助的に使用し、人が確認・調整」と明示 | §3.3の157人データ+透明性の両立 |
| プロフィール | 占い専門アカウントとして世界観統一。実績は実件数のみ記載(盛らない) | ベンチマークの型+景表法リスク回避 |
| やらないこと | 霊視・霊感を名乗る/お守り等の物販混合/500円均一の量販シリーズ/ページ数競争 | 霊感商法との距離を最大化+事業的利用リスク回避+時間予算 |

**残る確定事項(結パパさんの好みで決める)**:占い師名・キャラクター設定(女性的/中性的など)。→ 3点セット制作(Day 1〜3)の冒頭で決定します。
