# メルカリ占い 0→1ロードマップ v1(確定版)

> 作成日:2026-08-27 / 更新日:2026-08-27(v1)
> 状態:初版確定
> 位置づけ:`ROADMAP.md`(全体戦略)の実行編・前半。**0→1 = メルカリで入口商品の初売上を出し、アップセル初成約まで到達すること**
> 期間:30日(+改善延長2週まで)/ 週の投下時間上限:5時間

---

## 1. 0→1の定義と成功条件

**結論:30日以内に「入口商品の売上3件+アップセル成約1件」を取れたら0→1成功です。**

| 判定 | 条件(Day 30時点) | 次のアクション |
|---|---|---|
| ✅ 成功 | 入口売上3件以上+アップセル成約1件以上 | `ROADMAP-1-100.md` Stage 1 へ |
| 🔁 継続 | 入口売上1〜2件(アップセル未成約可) | 改善プロトコル(§7)で+2週延長。1回のみ |
| ❌ ピボット | 売上0件 | ジャンル替え(§7.3)して再スタート、または撤退判断 |

この期間の目的は売上金額ではなく「**売れる証拠と型の獲得**」です。金額目標は置きません(置くと不安煽り表現に流れやすくなるため)。

---

## 2. 前提条件チェックリスト(Day 0)

出品を始める前に、以下がすべて ✅ であることを確認します。

- [ ] メルカリアカウントの本人確認完了・売上金の振込先登録済み
- [ ] `ROADMAP.md` §2(法的境界)を読了。NG表現5類型を言える状態
- [ ] 鑑定書を**印刷して郵送**できる環境(自宅プリンタ or コンビニ印刷)+ゆうパケットポストmini(専用封筒)の理解
- [ ] 占い用アカウントの分離方針を決定(本業の物販アカウントと混ぜない。※メルカリは1人1アカウント規約のため、既存アカウントを使う場合は物販との併用リスクを了解した上で使う)
- [ ] リスク上限(§8)に同意:常時出品10件以内・単価1万円未満・売上金は都度振込

## 3. 30日プラン

### Day 1〜3:制作基盤(3点セット)

| やること | 成果物 | 完了条件 |
|---|---|---|
| 占い師プロフィール設計 | 名前・肩書き・世界観・プロフィール文(200字) | 「誰に何を届ける占い師か」が1行で言える |
| 主力占術の決定 | タロット×恋愛(推奨) | 1つに絞れている(複数占術は0→1では扱わない) |
| ヒアリング定型文 | 購入後に送る質問テンプレ(お名前(ニックネーム可)・生年月日・ご相談内容・お相手について) | コピペで送れる状態 |
| 鑑定プロンプト | AIへのシステムプロンプト(占い師ロール+口調+**NG表現の禁止事項を明記**) | サンプル生成でNG表現が出ないこと |
| 鑑定書テンプレ | CanvaのA4テンプレ(非AI素材)。表紙+鑑定本文+免責文欄 | PDF出力→印刷確認まで済んでいる |

### Day 4〜7:出品準備と初回出品

| やること | 完了条件 |
|---|---|
| サンプル鑑定3本を生成→**人力検品**(NG表現・個別性・誤字) | 3本ともNGゼロ |
| サムネ作成(Canva、非AI素材。「タロット鑑定書 郵送でお届け」等の大きい文字) | 入口用2枚 |
| タイトル作成(悩みキーワードを先頭に。例「彼の気持ち タロット鑑定書 郵送」) | 40字以内で検索語を含む |
| 説明文作成(§4のテンプレ) | 免責文・AI明示・「印刷した鑑定書を匿名配送」明記の3点が入っている |
| **入口商品2件を出品**:①彼の気持ち 580円 ②復縁 880円(価格根拠は `BENCHMARK.md` §1.5.4) | 出品完了 |

### Day 8〜14:運用開始(最初の売上を取りに行く)

- 毎日1回ログインし、閲覧数・いいねを記録(§6の記録シート)
- 出品の見直し(文言・画像の改善)は**週1回まで**。機械的な再出品・値下げ→戻しの繰り返しは「継続的出品」(事業的利用)と見なされるリスクを高めるため**行わない**(`ROADMAP.md` §2.3 の方針と一貫させる)
- コメントには12時間以内に返信(定型文を用意)
- **受注が入ったら§5の納品オペレーションを24〜48時間以内に完走**
- Day 14 時点で閲覧が極端に少ない(累計100未満)場合は、§7の改善プロトコルを前倒しで開始

### Day 15〜30:アップセルの型を回す

- 入口購入者への納品時メッセージに**アップセル一言**(§6)を必ず添える
- 希望者が出たら「○○様専用」出品(3,000円・詳細鑑定)を作成→案内
- 2件目以降の入口商品を追加(ツインレイ or 複雑恋愛。常時10件以内厳守)
- リピーター向け:取引完了メッセージに「またご縁がありましたら」+フォローのお願い

## 4. 出品説明文テンプレ(コピペ用)

```
【内容】
タロットカードであなたのご相談を鑑定し、A4の鑑定書(印刷物)を
匿名配送でお届けします。

【お届けするもの】
・鑑定書1部(A4・1〜2枚)※印刷物の郵送です
・カードの展開結果/読み解き/前向きに進むためのヒント

【ご購入後の流れ】
1. ご相談内容を質問フォーム(定型文)でお伺いします
2. 2日以内に鑑定書を作成し、発送します

【必ずお読みください】
・本サービスはエンターテインメント/自己分析を目的とし、医療・法律・
　投資の助言ではなく、結果を保証しません。最終判断はご自身で。
・鑑定文の作成にはAIを補助的に使用し、内容は占い手が確認・調整しています。
・深刻なお悩み(健康・法律・金銭)は専門機関へご相談ください。
```

**出品前セルフ検品(毎回)**:①断定表現なし ②不安煽りなし ③健康・医療への言及なし ④保証表現なし ⑤免責文あり——5つ全部○でなければ出品しない。

## 5. 納品オペレーション(受注1件の標準フロー)

| # | 工程 | 目安時間 | 注意 |
|---|---|---|---|
| 1 | ヒアリング定型文を送信→回答受領 | 5分 | 深刻な悩み(健康・多額の金銭)なら§8.3の対応 |
| 2 | AIで鑑定文を生成 | 5分 | プロンプトの禁止事項が効いているか目視 |
| 3 | **人力検品・リライト** | 10分 | NG表現チェック+相談内容に固有の一文を必ず追加 |
| 4 | 鑑定書テンプレに流し込み→印刷 | 5分 | 誤字・氏名の取り違えに注意 |
| 5 | 封入→ゆうパケットポストminiで発送 | 5分 | 発送通知+お礼メッセージ |
| 6 | 到着後:お礼+**アップセル一言**(§6) | 2分 | プル型。売り込まない |

1件あたり合計約30分。週5時間の枠なら受注対応は**週5件程度が上限**です(それ以上売れる場合は §8 の上限と相談)。

### 5.1 原価と粗利(郵送形態の現実)【2026-08-27 採算分析で確定】

配送は**ゆうパケットポストmini(送料160円+専用封筒20円=180円、追跡・匿名配送)を標準**とします。匿名配送は占い商材の重要な売りのため、定形郵便(110円・匿名性なし)は使いません。

| 項目 | 目安 |
|---|---|
| 販売手数料10% | 58円(580円時) |
| 送料+専用封筒(ゆうパケットポストmini) | 180円 |
| 印刷(A4カラー12円/枚×2〜5枚) | 24〜60円 |
| **粗利(580円時)** | **約280〜320円(約50〜55%)/時給換算 約600円** |
| **粗利(880円時)** | **約550〜590円(約63〜67%)/時給換算 約1,150円** |
| **粗利(3,000円時)** | **約2,460〜2,500円(約82〜83%)/時給換算 約5,000円** |

**580円は最初のレビュー獲得期(売上3件まで)の検証価格**(時給換算では成立しないが、検証コストとして許容)とし、以降の入口は**人件費込みで単体成立する880円**を標準とします。値上げの告知は「初回のお試し価格です。レビューが貯まり次第、通常価格に改定予定です」という**事実ベースの表現のみ**を使い、「通常◯◯円」等のアンカー価格表記は使いません(景表法・二重価格表示。`BENCHMARK.md` §1.5.1)。収支の記録は必ず原価控除後の実質額で行います。

※2026年10月に日本郵便の料金改定(平均約10%値上げ)が予定されています。Stage 1で原価を再計算してください。

## 6. アップセルの型

**原則:プル型。こちらから売り込まず、満足した人に「ある」と知らせるだけ。**

納品時メッセージ(定型):

> このたびはありがとうございました。鑑定書がお手元に届きましたら、感じたことをそのままで大丈夫ですので、よろしければ評価にてお聞かせください。
> なお、今回のテーマをさらに深く掘り下げる「じっくり詳細鑑定」もご用意しています。ご希望でしたら専用ページをお作りしますので、お気軽にお申し付けください。

- **主導線:誰でも購入できる「じっくり詳細鑑定」(3,000円・A4 3〜4枚)を通常出品として常設**し、案内はこの出品へ誘導する
- 「○○様専用」出品は補助手段。メルカリは専用出品を公式に保証しておらず**先着順販売が原則**のため、使う場合は①相手と合意後すぐ出品→即購入を依頼 ②万一第三者が購入した場合は**その取引をそのまま履行する**(断らない)——をルール化する
- **やってはいけない**:「このままだと良くない方向に…」等、不安を理由にした案内(霊感商法の型。`ROADMAP.md` §2)。断られたら二度と案内しない
- 記録:入口売上ごとに「アップセル案内→希望有無→成約」をスプレッドシートに記録(1→100のStage 1でこのデータが主役になります)

## 7. 売れないときの改善プロトコル

### 7.1 診断の順序(価格は最後)

2週間売上ゼロ→**サムネ→タイトル→説明文→価格**の順で、1要素ずつ・3日間隔で変更します(同時に変えると原因が特定できないため)。

| 症状 | 疑う場所 | 打ち手 |
|---|---|---|
| 閲覧が少ない(1日10未満) | サムネ・タイトル | 文字を大きく/悩みキーワードを先頭に(※機械的な再出品はしない) |
| 閲覧あり・いいねなし | サムネと価格のミスマッチ | サムネの訴求を1テーマに絞る |
| いいねあり・購入なし | 説明文 | 「何が届くか」を具体化/不安要素(納期・形態)を先回りで明記 |
| コメントで質問だけ来る | 説明文の情報不足 | 質問された内容を説明文に反映 |

### 7.2 変更ログ

変更は必ず「日付/変えた要素/変更前後/その後3日の閲覧・いいね」を記録します。記録なしの変更は禁止(何が効いたか分からなくなるため)。

### 7.3 ピボット(Day 30で売上0件)

ジャンルを「彼の気持ち」→別の上位ジャンル(復縁 or ツインレイ)へ替えて§3をもう1周(2週間)。それでも0件なら、メルカリ検証は撤収し `ROADMAP-1-100.md` Stage 2(ココナラ)へ直行します。**メルカリで売れないこと自体も有効な検証結果**であり、失敗ではありません。

## 8. リスク上限と撤退基準(常時適用)

### 8.1 上限

| 項目 | 上限 | 理由 |
|---|---|---|
| 常時出品数 | 10件以内 | 事業的利用(2025年10月改定で禁止)と見なされるリスクの低減 |
| 単価 | 1万円未満 | 高額出品ほど通報・削除の対象になりやすい |
| 売上金 | 都度振込申請 | アカウント停止時の売上金凍結リスクの低減 |

### 8.2 即時撤退トリガー(1つでも該当したら出品を止めて判断)

- 出品削除・警告がメルカリ運営から届いた(**再出品はしない**。ココナラ移行を前倒し)
- 検索結果に表示されなくなった(圏外飛ばしの兆候)
- 取引でトラブル(受取評価拒否・返金要求)が2件連続

### 8.3 対応してはいけない相談

健康・病気/多額の金銭(投資・借金)/自傷や深刻な精神的危機——これらの相談が来たら鑑定せず、丁寧にお断りして専門機関(医療機関・法テラス・いのちの電話等)を案内し、キャンセル手続きをします。定型文をDay 1〜3で用意しておきます。
