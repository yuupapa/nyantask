## 1. アカウント画面の設計

**前提**:メルカリのプロフィール画面には「背景(カバー画像)」を設定する公式機能が存在しない。購入者が見る順序は「①アイコン→②表示名→③プロフィール文→④出品一覧(グリッド)」の4段階。視覚的第一印象は出品一覧のサムネ群が実質的に担う。

### 1-1. アイコン(確定仕様)

| 項目 | 仕様 |
|---|---|
| 形状 | 正方形1:1で作成(円形トリミング表示のため四隅に重要要素を置かない) |
| 地色 | 生成りクリーム #FAF1E4 |
| 主モチーフ | 横倒しの「8」(=∞)を中央に手描き風の丸みある線画で。色はくすみブルー #A9C4D8 |
| 副モチーフ | ∞の左右か下に小さな星3つ(薄色のアクセントに留める) |
| 人物要素 | 入れない(顔出し・シルエットとも。実測3/3が顔出しなし) |
| 文字 | 入れない(記号のみ。名前は表示名で担保) |
| 禁止 | 紫グラデ・ネイビー×ゴールドの神秘系配色 |

### 1-2. 「背景」の扱い

1. 出品一覧1枚目サムネの統一デザインを事実上のブランド背景として機能させる(§4)
2. アイコン地色をサムネ共通ベースカラーと揃え、プロフィール→出品一覧までトーンを途切れさせない

### 1-3. 表示名

```

```

### 1-4. プロフィール文の構成(4ブロック+価格帯1文)

| ブロック | 役割 |

**④の直前に追加する1文**(価格帯の全体像を事前提示し、入口だけ見て離脱するのを防ぐ):


### 1-5. 出品一覧の見え方

メルカリの出品者ページは**手動並べ替え不可・既定は新着順**。よって:

- 新規入口商品(888円)を追加するたびに一覧の最上段に来る
- 常設の詳細鑑定(2,888円)は沈んでいくが、**サムネの配色だけ他と異なる(マスタードアクセント)**ため一目で「上位グレードが混ざっている」と分かる
- 結果として「入口が並ぶ中に色味の違う高単価が1点混ざる」松竹梅の視覚構成が自然に成立する

## 3. 検索キーワード設計

**共通ルール**:タイトル40字は「①悩みキーワード(先頭)→②数秘術→③鑑定書(必須)→④匿名配送/郵送→⑤余白があれば補助語」の優先順。スペース区切りでトークンを分離。「24時間以内」「即日」等、実納期(24〜48h)を超える速度訴求はしない。

**3商品の判定**:①②は現行タイトルのままで合格。**③は「じっくり詳細鑑定」という自社造語が先頭で検索に弱いため改訂**:

## 4. 商品間の導線設計

手動並べ替え不可のメルカリでは、導線は次の3点の組み合わせのみで作る。

1. **サムネの2軸ルール**:ジャンル軸(恋愛全般=くすみブルー/復縁=くすみピンク/以降パレット内で拡張)+グレード軸(詳細鑑定のみマスタードアクセント)。全出品の1枚目右上に「八」ロゴバッジを統一配置し同一シリーズ感を出す
2. **説明文の相互参照文**(listings.mdに反映済み):入口①②には詳細鑑定の案内1文、③には「はじめての方もご購入いただけます」の1文
3. **プロフィール文の価格帯1文**(§1-4)

## 5. 週次運用カレンダー(週5時間・受注5件以内)

受注は非同期発生のため「毎日5〜10分の定点観測+受注時その場対応(24〜48h完走)」が基本。固定曜日は週1改善と週1レビューのみ。

| 曜日 | 作業 | 目安 |
|---|---|---|
| 月〜土 | ログイン→閲覧数・いいね記録→コメント返信(12h以内)→受注対応(あれば32分/件) | 各10分+受注分 |
| 水 | +出品メンテ(週1回。§7の順序でサムネ→タイトル→説明文→価格の1要素のみ、中3日空ける) | +60分 |
| 日 | +週次レビュー(PV・いいね・受注・アップセル案内数/成約数を記録) | +30分 |

合計 約5.3h/週(受注5件未満の週は差分をココナラ仕込みに充当)。

## 6. ココナラ移植を見据えた区別

**流用できる資産**:数秘計算ロジック・鑑定プロンプト/世界観・モチーフ(配色はココナラ実測の定番に合わせ別トラック)/説明文の構成ロジック/免責文・誠実路線/定型文/実績数値(実件数)。

**メルカリ限りの資産(持ち込まない)**:
- 888/2,888円ラダーの構造(ココナラはNnatty型のお試し500円→段階改定に再設計。888の縁起は残してよい)
- タイトルSEOの型(ココナラは前半15文字ルール+新着枠の別アルゴリズム)
- 印刷物郵送の納品形態(ココナラは役務販売が公式。チャット/PDF/電話をStage 2で正式採用し、原価ゼロ前提で価格を再計算)
- 「○○様専用」運用(ココナラは公式の見積もり・カスタム機能で代替)
- 出品10件上限(ココナラは逆に最大20サービス+定期追加で新着枠を稼ぐ運用)

**プラットフォーム分離**:メルカリの出品文・プロフィールにココナラの存在を示唆する文言(外部誘導)は一切書かない。
