# 実地観察チェックリスト(結パパさん作業)

> 目的:`design-evidence.md` で **C(二次情報)・D(推測)** 止まりになっている判断を、**A(実測)** に上げる。
> 方法:Chromeでメルカリにログインし、拡張機能のClaudeに画面を見せて答えさせる。所要は合計20〜30分の想定です。
> 結果は貼り付けていただければ、こちらで `BENCHMARK.md` と `design-evidence.md` に反映します。

## 観察1:ベンチマーク3アカウントの「2枚目以降」の画像(最優先)

いまサムネの1枚目の型だけが実測で確定していて、**2枚目以降が完全に未確認**です。ここが埋まると出品画像の構成が確定します。

対象は `BENCHMARK.md` §1.2 の3アカウント(A:ゆうま / B:葵ゆい / C:霊視系)。各アカウントの**売れている出品を2〜3件**開いて、次を見てください。

- [ ] 画像は全部で何枚あるか
- [ ] 2枚目は何か(鑑定書の見本 / お客様の声 / 流れの説明 / 注意書き / その他)
- [ ] 3枚目以降の内容と順番
- [ ] **鑑定書の見本画像はあるか**。ある場合、それは次のどれか
  - 印刷した紙を**実際に撮影した写真**(手に持つ、机に置く、封筒と一緒 など)
  - パソコン上のテンプレートの**スクリーンショット**
  - 中身が読めないようモザイク・ぼかしをかけたもの
- [ ] **封筒・便箋・切手など「発送物」の写真**はあるか
- [ ] お客様の声を載せている場合、どういう見せ方か(スクショ貼り付け / 文字に起こして画像化 / 件数や評価の数字を出しているか)

### Claudeへの聞き方(そのままコピーして使えます)

```
この出品ページの商品画像を1枚目から順に見て、次の表にまとめてください。
| 枚目 | 何が写っているか | 文字は入っているか(入っていればその文言) | 写真か作図か |
また、鑑定書の見本が写っている画像があれば、それが実物の写真か、パソコン画面のスクショかを判定してください。
```

## 観察2:AI画像に関する規約の原文確認(出品前に必須)

`design-evidence.md` §4 の判断は、**条文の原文を1件も読めていません**(調査環境から到達できませんでした)。
出品前にご自身のブラウザで開いて、スクリーンショットを保存してください。ここが違っていると設計の前提が崩れます。

- [ ] メルカリガイド「禁止されている行為」の一覧
- [ ] メルカリの**生成AI・加工画像に関する注意点**(2026年3月公開とされるもの。メルカリびより)
  - 確認したいこと:**イメージ画像を使う場合に実物写真の併載が求められているか**。ここが今の設計の土台です
- [ ] メルカリ利用規約の「実体のないもの(役務・権利)の出品禁止」条項
- [ ] ココナラ「AI技術を使用した出品に対するスタンス」
  https://coconala-support.zendesk.com/hc/ja/articles/48479864968729
  - 確認したいこと:禁止されているのは**イラスト**画像だけか。**写真**画像は許容されているか。「素材として一部使用」も禁止対象に含まれるか

※ 以前からお願いしている Day 0 の原文確認3件(メルカリ規約2件・消費者庁の二重価格)と重なる部分があります。まとめて済ませてしまうのが早いです。

## 観察3:鑑定書の実物がどう見えているか

これが**いちばん確証が薄い**ところです。他の占い師が実際に送っている鑑定書を、まだ1件も見ていません。

- [ ] 「鑑定書」で検索し、**SOLD済み**の出品を10件ほど開く
- [ ] 商品画像に鑑定書の中身が写っているものがあれば、次を見る
  - 縦書きか横書きか
  - 明朝体か、ゴシックか、手書き風か
  - 背景に模様・イラストはあるか。あるならどんな絵柄か(星・月・花・和紙・幾何学 など)
  - 枠や罫線はあるか。色は何色か
  - 署名・サイン・印章はあるか
- [ ] 購入者のコメント欄に、鑑定書の**見た目**に触れた文があれば、その文言をそのままコピー

### Claudeへの聞き方

```
この出品の画像に鑑定書の中身が写っていたら、レイアウトを言葉で描写してください。
縦書きか横書きか、書体、背景の模様の有無と絵柄、枠線の色、署名や印の有無を、見えたままに。
推測は書かず、見えないものは「写っていない」と答えてください。
```

## 観察4:自分で印刷して撮る(出品画像用)

メルカリの規定が「イメージ画像を使う場合は実物写真を併載」を求めているため、**この写真は出品に必須**です。
兼ねて、信頼形成の材料にもなります。

- [ ] `kanteisho-template.html` をブラウザで開き、サンプル鑑定(`sample-kantei.md`)を流し込んでA4カラー印刷する
- [ ] 印刷した2枚を撮影する。撮り方の目安
  - 明るい自然光(昼間の窓際)。蛍光灯の直下は色が転ぶので避ける
  - 無地の白木のテーブルか、白い紙の上に置く
  - 真上から1枚、少し角度をつけて1枚
  - 封筒(ゆうパケットポストmini)と並べて1枚
  - **個人情報が写らないよう、宛名はサンプル名(「みさき さま」等)のまま**にする
- [ ] 撮った写真を送ってください。トリミング・明るさ調整をして出品画像の1枚に組み込みます
