# 取引メッセージ定型文集(コピペ用)

> 作成日:2026-08-27 / `ROADMAP-0-1.md` Day 1〜3 成果物③

## 1. ヒアリング(購入直後に送る)

```
このたびはご購入ありがとうございます。【男性心理×数秘】八雲です。
鑑定のため、以下をご返信ください。

①あなたのお名前(ひらがな・ニックネーム可)
②あなたの生年月日(西暦)
③お相手のお名前(ひらがな・下のお名前だけでも大丈夫です)
④お相手の生年月日(分かる範囲で。不明でも鑑定できます)
⑤ご相談内容(いま一番気になっていることを自由にお書きください)

ご返信をいただいてから24〜48時間以内に鑑定書を作成し、発送いたします。
```

## 2. 発送通知

```
お待たせいたしました。鑑定書を本日発送いたしました(匿名配送)。
数字の計算過程も載せていますので、ゆっくりお読みください。
お手元に届きましたら、受取評価にてお知らせいただけると幸いです。
```

## 3. 納品後のお礼+アップセル一言(プル型・売り込まない)

```
このたびはありがとうございました。鑑定書がお手元に届きましたら、
感じたことをそのままで大丈夫ですので、評価にてお聞かせください。

なお、今回のテーマをさらに深く掘り下げる「じっくり詳細鑑定」
(3つの数字とこれからの流れまで読む A4・3〜4枚)もご用意しています。
ご希望でしたらお気軽にお申し付けください。
```

※断られたら二度と案内しない。「このままだと…」等、不安を理由にした案内は絶対にしない(`../ROADMAP.md` §2)

## 4. お断り定型文(対応してはいけない相談が来たとき)

健康・病気/多額の金銭(投資・借金)/生死・深刻な精神的危機の相談には使用(`../ROADMAP-0-1.md` §8.3):

```
ご相談をお寄せいただきありがとうございます。
大変心苦しいのですが、健康・医療、金銭、その他専門的な判断を要する
お悩みは、占いでお応えしてよい範囲を超えるため、鑑定をお受けして
おりません。どうか専門の窓口(医療機関・法テラス・自治体の相談窓口など)
にご相談ください。

本件はキャンセル手続きをさせていただきます。
あなたの毎日が穏やかであるよう願っています。
```

## 5. コメント返信(購入前の質問)

```

{回答}
鑑定書は印刷物を匿名配送でお届けしますので、どうぞご安心ください。
```

```
このたびはご縁をいただきありがとうございました。
またお話を伺える日がありましたら、いつでもお声がけください。
よろしければフォローしていただけると、新しい鑑定メニューを
ご案内できます。
```
