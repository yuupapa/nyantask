## 0. ブランド共通仕様

### 0.1 配色パレット(全商品共通・フラットカラーのみ・グラデーション不使用)

| 役割 | 名称 | HEX | 用途 |
|---|---|---|---|
| BASE | 生成りクリーム | `#FAF1E4` | 背景ベース色(全枚共通) |
| SUB-BG | くすみピンク | `#F4CFCB` | 商品②(復縁)のメインブロブ・アクセント面 |

### 0.2 フォント指定(Canva内の日本語フォント名で検索・選択)

| 用途 | フォント名(Canva検索名) | ウェイト | サイズ目安 |

| タグ帯(小ラベル) | **Zen Maru Gothic** | Bold | 24px |

### 0.4 「八雲」署名の置き方(全商品固定)

- 位置:1〜3枚目すべての右下、中心座標(945,945)、直径110pxの円
- 円の中身:背景 `#FAF1E4`、縁は`#4A3E38`の1.5px線
- 円内テキスト:1行目「八雲」(Shippori Mincho Medium・22px・`#4A3E38`)、2行目に小さく「∞」(14px・`#E3A857`)
- 顔写真・似顔絵は一切使わない(実測3/3が顔出しなしのため)

## 1. 商品① 彼の気持ち(888円)

### 1枚目(メインサムネ)

**背景**:`#FAF1E4`全面+薄い幾何学パターン(不透明度8%、`#4A3E38`のドット柄または細線グリッド)。Canva素材検索:「ドット柄 パターン 背景」「幾何学模様 背景 シンプル」→色をTEXTに変更→透明度8%。

**ゾーンA タグ帯**:ピル型(幅200px×高さ56px中央配置)。背景`#E3A857`、文字「数秘術鑑定書」白・Zen Maru Gothic Bold・24px。

**ゾーンB メインビジュアル**:中心(540,400)に直径560pxのブロブ、色`#A9C4D8`。輪郭は「有機的な図形 ブロブ」で少し歪んだ丸型。内側中央やや左に「男性 横顔 シルエット イラスト フラット」(線画・`#4A3E38`)高さ320px。右下に大きな数字「8」(Extra Bold・180px・`#E3A857`)。

**ゾーンC メインコピー**:2行・中央揃え。「数字で読む、」「彼の本音。」Zen Maru Gothic Extra Bold・78px・`#4A3E38`。背後に820×140pxの白(不透明度75%)角丸長方形。

**ゾーンD サブコピー**:「数秘術鑑定書|彼の気持ち」Medium・30px。

**ゾーンE 必須帯(2本)**:
- 帯1(y=860〜926):幅900×高さ64px角丸、背景`#E3A857`、「鑑定書を郵送|匿名配送」白・Bold・30px

### 2枚目(鑑定書イメージ)

## 4. Canva操作手順(15分で3商品・9枚)

### 4.0 事前準備(2分)

1. 新規デザイン→カスタムサイズ「1080×1080px」
2. ブランドカラー5色(§0.1のHEX)をカラーパネルに登録
3. 「Zen Maru Gothic」「Shippori Mincho」をお気に入り登録

### 4.1 素材検索キーワード一覧

| 用途 | 検索キーワード |
|---|---|
| 背景パターン | ドット柄 パターン 背景/幾何学模様 背景 シンプル |
| ブロブ・図形 | 有機的な図形 ブロブ/シンプル 図形 曲線 |
| 男性シルエット | 男性 横顔 シルエット イラスト フラット |
| 二人シルエット | 二人 シルエット イラスト フラット 男女 |
| 人物(共通) | 人物 シルエット イラスト フラット |
| 紙モックアップ | 紙 ドキュメント イラスト フラット/A4 用紙 モックアップ イラスト |
| 表・グラフ | 表 グラフ アイコン フラット |
| 各種アイコン | ショッピングカート/チャット 吹き出し/電卓 計算/封筒 郵便/矢印 シンプル/チェックマーク(いずれも「アイコン フラット」を付ける) |

※検索後は色フィルターでパステル系に絞り、**「AI」ラベル付き素材は除外**(非AI素材のみ)。

### 4.2 作業手順(15分)

1. (5分)商品①1枚目をグリッドどおり作り込む=マスターテンプレート
2. (1分)複製→②の差分適用(色・イラスト・数字・文言)
3. (2分)複製→③の差分適用(3円構成・帯3本)
4. (3分)商品①の2・3枚目を作成
5. (2分)複製→②の差分適用(3枚目は流用)
6. (2分)複製→③の差分適用(紙4枚・比較表)

### 4.3 書き出し設定

- 「共有」→「ダウンロード」→**PNG**、透明背景**オフ**、商品ごとに該当3ページのみ選択
- ファイル名:`商品1_1枚目.png`形式(出品時のアップロード順ミス防止)
