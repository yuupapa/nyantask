# 鑑定書 挿絵の生成プロンプト集(GPT-Image / Grok Image 用)

> 作成日:2026-08-27 / 用途:`kanteisho-template.html` の背景挿絵レイヤー(`.bg-art`)
> 生成した画像をテンプレートと同じフォルダに `art-cover.png` `art-body.png` として保存し、HTML内のコメントを外すだけで反映されます(不透明度8%で文字の邪魔をしない設計)

## 使いどころのルール(先に確認)

| 使う場所 | 判定 | 理由 |
|---|---|---|
| **鑑定書の背景挿絵**(納品物の中) | ✅ 使ってよい | メルカリに納品物内のAI画像を禁じる規定はない。免責文に「挿絵の作成にAIを補助的に使用」を追記済み(透明性の担保) |
| **サムネ・出品画像** | ❌ 使わない | ココナラは出品画像のAI生成イラストを禁止(Stage 2移植時に作り直しになる)。メルカリ段階からCanva非AI素材で統一しておく方が資産になる(`thumbnail-spec.md` の方針どおり) |
| プロフィールアイコン | ❌ 使わない | 同上 |

## 共通の世界観指定(全プロンプトの土台)

- 淡い水彩・生成りアイボリー地(#FBF9F4系)/くすみブルー(#8A9BB0)と淡い金(#C4B28A)の2色まで
- モチーフは数字・「8」・「∞」・星・細い幾何学線のみ(タロット・水晶玉・人物・顔は入れない)
- **文字を入れない/中央は大きく空ける**(本文が乗るため、絵は四隅・縁に寄せる)
- 不透明度8%で敷いた時に品よく見える=線は細く、色は薄く

## プロンプト1:表紙用(art-cover.png)

```
やわらかい水彩画の背景素材。生成りのアイボリー地に、くすみブルーと淡い金色だけを使う。
画面の四隅と縁に、細い線で描いた小さな「8」の数字、無限大記号(∞)、小さな星、
細い幾何学的な円弧をまばらに散らす。中央は大きく余白として空ける。
人物・顔・文字・タロットカード・水晶玉は描かない。
上品で静かな和モダンの雰囲気。A4縦(2480×3508px)、余白多め、ミニマル。
```

```
生成りのアイボリー地の水彩背景。画面の下辺に沿って、淡い金色の細い線で
1から9までの数字と「∞」が小さく流れるように並ぶ帯を一本だけ描く。
それ以外は無地の余白。くすみブルーの小さな星を右上に3つ。
```

## 反映手順(3分)

1. 上のプロンプトで生成(候補を数枚出して、いちばん「うるさくない」ものを選ぶ)
2. `art-cover.png` / `art-body.png` の名前で `kanteisho-template.html` と同じフォルダに保存
3. HTML内の `<!-- <img class="bg-art" ... -->` のコメントを外す
4. ブラウザで開いて確認→印刷プレビューで「背景のグラフィック」チェックを確認
5. **印刷して1枚テスト**(画面より紙は色が濃く出やすい。濃すぎたら style="opacity:.05" に下げる)

## 検品基準

- [ ] 文字・人物・顔が入っていない
- [ ] 本文の可読性を一切妨げない(印刷して音読できるか)
- [ ] タロット・水晶玉など他店の神秘系モチーフが混ざっていない
- [ ] 表紙と本文で世界観が揃っている
