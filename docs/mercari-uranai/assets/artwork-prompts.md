# 鑑定書 挿絵の生成プロンプト集(GPT-Image / Grok Image / Gemini 用)

> 作成日:2026-08-27(2026-08-27 改訂)/ 用途:`kanteisho-template.html` の背景挿絵レイヤー(`.bg-art`)
> 既定では **AI画像を使わない線画版**(`images/art-cover.png` / `art-body.png`、`tools/gen-art.py` で生成)が入っています。
> この文書は、それをAI生成画像に**差し替えたい場合**の手順とプロンプトです。

## 使いどころのルール(2026-08-27 改訂)

**改訂前は「サムネにAI画像は不可」としていましたが、これは誤りでした。**
ココナラの制限を、規定のないメルカリにまで広げて適用していたためです。正しくは次のとおりです(根拠は `design-evidence.md` §4)。

| 使う場所 | 判定 | 条件・理由 |
|---|---|---|
| **鑑定書の背景挿絵**(納品物の中) | ✅ 使える | メルカリの生成AI画像の規定は「出品ページに載せる画像」が対象。納品物の中身を規制する条文は見つからなかった |
| **メルカリの出品画像**(サムネ含む) | ✅ 使える(条件つき) | メルカリが求めているのは「イメージ画像を使う場合でも**実物の写真を必ず併せて掲載する**」こと。AI画像だけで構成しなければよい。→ **印刷した鑑定書の実物写真を1枚必ず入れる** |
| **ココナラの出品画像・納品物** | ⚠️ **イラスト調は不可 / 写真調は可** | ココナラはAI生成の**イラスト**画像を、素材として一部使っただけでも禁止している。一方でAI生成の**写真**画像は許容と案内している |

**したがって本プロジェクトの方針**:横展開時に作り直さずに済むよう、**AI画像を使うなら「写真調」で生成する**。
水彩画・線画・イラスト調は、メルカリでは通ってもココナラで引っかかります。

> いずれの規定も**原文を確認できていません**(調査環境から到達不可)。
> 出品前にご自身のブラウザで確認してください。項目は `observation-checklist.md` 観察2にまとめてあります。

## 共通の世界観指定(全プロンプトの土台)

- 生成りアイボリー地(#FBF9F4系)/くすみブルー(#8A9BB0)と淡い金(#C4B28A)以外の色を入れない
- **写真調**で生成する(紙の繊維、光のにじみ、インクの滲みなど、実在の物を撮影したように)
- **文字を入れない/中央は大きく空ける**(本文が乗るため、絵は四隅・縁に寄せる)
- 入れないもの:人物・顔・タロットカード・水晶玉・蓮・曼荼羅・天使・御札・数珠・封蝋
  (最後の5つは、国民生活センターが注意喚起する開運商法のイメージに近づくため。`design-evidence.md` §2)
- プロンプトに**実在の作家名・作品名・キャラクター名を入れない**(既存著作物への依拠性を持たせないため)

## プロンプト1:表紙用・写真調(art-cover.png)【推奨】

```
上質な生成りの紙をま上から撮影した写真。紙の繊維の質感が細かく見える。
斜めから柔らかい自然光が差し、右上から左下へゆるやかな明暗のグラデーションができている。
紙の四隅近くに、淡い金色の箔押しのような細い線がわずかに光る。
中央は何も置かれていない無地の余白。文字・人物・顔・イラストは写っていない。
静かで上品。A4縦の比率、2480×3508ピクセル。
```

```
上質な生成りの紙をま上から撮影した写真。表紙よりさらに控えめ。
紙の繊維の質感だけがわずかに見え、上端と下端にごく淡い光のにじみがある。
```

```
滲みは画面の左上と右下の隅にだけあり、中央は無地。
```

## 反映手順

1. 上のプロンプトで生成(候補を数枚出して、いちばん「うるさくない」ものを選ぶ)
2. **逆画像検索で酷似する既存作品がないか確認**(著作権侵害リスクの確認。`design-evidence.md` §4.3)
3. `art-cover.png` / `art-body.png` の名前で `assets/images/` に保存(既存の線画版を上書き、または別名にして src を変更)
4. **`.bg-art` の `opacity` を `1` から `.10`〜`.15` に下げる**
   線画版は画像側で最終濃度まで作り込んであるので `opacity: 1` ですが、写真調の画像はそのままだと濃すぎて本文が読めません
5. ブラウザで開いて確認 → 印刷プレビューで「背景のグラフィック」にチェックが入っていることを確認
6. **印刷して1枚テスト**(画面より紙は色が濃く出やすい)
7. 免責文を「鑑定文**および挿絵**の作成にはAIを補助的に使用し」に戻す
   (現在は線画版なので「鑑定文の作成には」となっています。事実と合わせてください)

## 検品基準

- [ ] 文字・人物・顔が入っていない
- [ ] **イラスト調になっていない**(ココナラ横展開時に引っかかります)
- [ ] 本文の可読性を一切妨げない(印刷して音読できるか)
- [ ] タロット・水晶玉・蓮・曼荼羅・御札など、開運商法を連想させるモチーフが混ざっていない
- [ ] 表紙と本文で世界観が揃っている
- [ ] 逆画像検索で酷似する既存作品が出てこない
