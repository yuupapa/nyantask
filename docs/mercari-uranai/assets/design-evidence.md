# デザイン判断の根拠表

> 目的:サムネ・アイコン・鑑定書のデザインを「なんとなく良さそう」で決めないための根拠台帳。
> 各項目に**検証度ラベル**を付けます。ラベルの低い判断は、実地観察で確認するまで暫定扱いです。
> 関連:`BENCHMARK.md`(実測データ)/ `thumbnail-spec.md`(仕様)/ `ROADMAP.md` §2(法的境界)

## 0. 検証度ラベルの定義

| ラベル | 意味 |
|---|---|
| **A:実測** | 結パパさんがメルカリ上で実際に見た出品・アカウントの観察結果(`BENCHMARK.md` §1.2) |
| **B:一次情報** | 公的機関・プラットフォーム公式・研究機関の発表を確認 |
| **C:二次情報** | Web検索のスニペット・要約由来。原文ページは未閲覧(調査時点でegress遮断) |
| **D:推測** | 上記から導いた仮説。実証されていない |

> 2026-08-27時点の調査環境では、mercari.com / coconala.com / note.com / 消費者庁・国民生活センターの各ページへ**直接アクセスできませんでした**。
> そのため C ラベルは検索結果のスニペットが根拠であり、原文照合は済んでいません。この制約を伏せずに記録します。

## 2. 鑑定書(納品物)

**重要な区別**:サムネは「クリックさせるための集客物」、鑑定書は「受け取った人が本物と感じるための納品物」。
評価軸が違うため、**サムネで否定されたネイビー×ゴールドが鑑定書では定番色**という逆転が起きます。混同しないこと。

| 判断 | 根拠 | 検証度 |
|---|---|---|
| A4の背景画像(PNG)を敷き、その上にテキストを流し込む | 業界の標準的な制作法。Chrome拡張「占い鑑定書メーカー」は背景画像をJPG/PNG(A4推奨)で差替える仕様を公開しており、この作り方が前提になっている | **C**(ツールの公開仕様) |
| 本文は明朝体 | 明朝体は「証書・正式文書」の印象を与えるとして占い系デザインで推奨される | **C** |
| 横書きA4。縦書き和風にしない | 制作ツール(Canva/スライド/Word)が横書き前提で業界標準。縦書きは霊視・四柱推命系との混同を招く | **C** / 混同リスクは**D** |
| 数秘術の記号は「数字×幾何学(星・円環)」 | 数秘術系の素材は「星座+数字」の宇宙的モチーフが主流。ホロスコープ円盤図(占星術)との差別化になる | **C** |
| 蓮・曼荼羅・天使・御札・数珠のモチーフを使わない | スピリチュアル素材の定番だが、国民生活センターが注意喚起する開運商法のイメージに接近する。除霊・呪い・護符販売が「怪しい占い師」の典型として名指しされている | 注意喚起=**B** / 接近リスク=**D** |
| 落款・朱印を使わない | 占い鑑定書に印章文化を援用する慣行は**確認できなかった**。無い慣行を足すと浮く | 確認できず→不採用 |
| 手書き風の一言メッセージ欄を設ける | 手書きメッセージは読み手に「時間がかかった」「思いが込められている」(速記比)、「丁寧」(タイプ比)と評価されるという実験結果。被験者40名 | **B**(NTTデータ経営研究所ほか アナログ価値研究会 2017-07-04) |
| 構成は「表紙+本文+鑑定士プロフィール」 | 業界の型。タロット4枚(表紙+鑑定2+プロフィール)、四柱推命3枚(表紙+鑑定+プロフィール)という区分が制作サービス側で語られる | **C** |
| ページ数・文字数を商品説明で明示する | ココナラ占いの高評価レビュー頻出語が「丁寧」「長文でボリュームがある」「対応が早い」 | **C** |
| テンプレ使い回し感を避け、相談内容に固有の一文を必ず入れる | 低評価の主因が「先生違いで結果がほぼ同一(コピペ疑惑)」「誤字脱字だらけ」 | **C** |
| 断定を避け、前向きな助言で締める | バーナム効果(1956年 ポール・ミール命名)を利用した記述は断定を避けるのが定石。かつ断定は景表法リスク | 概念=**B** / 実務=C |

### 2.1 背景挿絵の具体仕様(2026-08-27 改訂)

**改訂の理由**:初版は `∞` と `8` と星を薄く散らしただけで、**根拠がなく、かつ印刷しても視認できない濃度**でした(2480×3508pxで確認)。上表の根拠に沿って作り直します。

| 要素 | 仕様 | 根拠 |
|---|---|---|
| 主モチーフ | 数秘の円環図(同心円+9分割の目盛+中心の九角星)。本文ページのみ円周に数字1〜9を出す | 数秘術=数字×幾何学(C)。ホロスコープ円盤との差別化(C)。**表紙で数字を出さない理由**:9は奇数なので円周の頂点と底点を同時に空けられず、数字が必ずタイトルか署名に接触する(自己検証) |
| 色 | くすみブルー `#8A9BB0` / ゴールド `#C4B28A` の細線のみ | 洋風・数秘系の定番色域(C)。彩度を抑え開運商法的な派手さを回避(D) |
| 濃度 | 画像そのものを最終濃度で作る(CSS側の `opacity` は 1 に変更) | 初版は画像が薄い上にCSSで8%に落としていたため完全に消えていた(自己検証) |
| 配置 | 表紙=紙面中央(y=1754px・半径780px)に円環図、四隅に角罫と小さな星。本文=上下端に円環の一部が覗くのみ、中央は無地 | 表紙は ∞・タイトル・宛名が円の中に収まる位置。本文は可読性を優先(自己検証) |
| 使わない | 蓮・曼荼羅・天使・御札・数珠・封蝋・水晶・タロット図像 | 開運商法イメージへの接近リスク(B+D)。タロット図像は数秘術と占術が食い違う |

## 4. AI生成画像はどこまで使えるか

**先に訂正**:当初このプロジェクトでは「サムネ・アイコンにAI画像は不可、鑑定書内の挿絵のみ可」という線引きをしていました。
これは**根拠より厳しすぎる誤りでした**。ココナラの制限を、規定のない場所(メルカリ)にまで広げて適用していたためです。
以下が調べ直した結果です。ただし後述のとおり**条文の原文は1件も確認できていません**(調査環境からmercari.com・coconala.comへ到達不可)。

### 4.1 用途ごとの可否

| 用途 | 可否 | 条件・根拠 | 検証度 |
|---|---|---|---|
| **メルカリの商品画像**にAI生成の背景を使い、文字は自分で組む | **使える** | メルカリ公式が2026年3月に公開した生成AI・加工画像の注意点は、①傷や使用感を加工で隠さない ②「実物の写真」に見せかけた虚偽画像を使わない ③イメージ画像を使う場合でも**実物の写真を必ず併せて掲載する**、が骨子。禁止されているのは生成AI画像**だけ**で構成することであり、実物写真を別に載せれば装飾目的の併用まで禁じてはいない | **C** |
| **郵送する鑑定書**の背景挿絵にAI画像を敷く | **使える** | 上記はいずれも「出品ページに載せる画像」を対象にした規定。購入者に届く紙の中身のデザインを規制する条文は見つからなかった | **C**(不在の確認なので弱い) |
| **ココナラ**のサービス画像・納品物にAI画像 | **イラスト調は不可 / 写真調は可** | ココナラは「AIにより生成した**イラスト**画像」と「それを**素材として一部使用**したコンテンツ(サムネイル画像・動画等を含む)」を禁止する一方、「AIにより生成した**写真**画像」とその一部使用は許容と案内している。**加工したから大丈夫という理屈が通らない**のがメルカリとの決定的な違い | **C** |

### 4.2 この違いが実務に効くところ

- メルカリだけを見れば、AI背景+自作の文字組みは問題ありません。結パパさんの見立てのとおりです
- 引っかかるのは**ココナラへ横展開したとき**です。イラスト調のAI画像は、背景として一部使っただけでも禁止側に入ります
- したがって取れる道は2つ:**(1)** AI画像は写真調(星空・紙の質感・光など写実的なもの)に寄せて作り、両プラットフォームで同じ素材を使う / **(2)** メルカリ用はイラスト調で作り、ココナラ用に差し替える前提で運用する
- **推奨は(1)**です。差し替え運用は作業が二重になり、どちらを出したか取り違える事故が起きます

### 4.3 AI画像を使うときに守ること

| 守ること | 理由 | 検証度 |
|---|---|---|
| 出品ページに**印刷した鑑定書の実物写真**を必ず1枚入れる | メルカリの規定が求めている条件そのもの。イメージ画像だけの出品にしない | **C** |
| 商品説明で「手描き」「オリジナル原画」と書かない | AI生成物を人の手によるものと誤認させる表示になる。景表法の観点でも避ける | **C**+D |
| プロンプトに実在の作家名・作品名・キャラクター名を入れない | 生成物が既存著作物と**類似性**および**依拠性**を満たせば、通常の著作権侵害と同じ枠組みで侵害になり得る(文化庁「AIと著作権に関する考え方について」令和6年3月) | **C**(原文未確認) |
| 生成した画像は逆画像検索で酷似作品がないか確認する | 同上 | D |
| 鑑定書の免責文には「鑑定文の作成にAIを補助的に使用」と事実どおり書く | 現在の背景はAI画像ではなく線画のため、挿絵まで含める書き方は不正確 | 自己確認 |

### 4.4 今の成果物がどうなっているか

- **サムネ9枚・アイコン**:AI画像を含みません(タイポグラフィと幾何図形のみ)。実測(A)に基づく設計なので、このまま使えます
- **鑑定書の背景**(`images/art-cover.png` / `art-body.png`):数秘の円環図の線画で、AI画像ではありません。**規約リスクゼロの標準版**として残します
- AI画像版を作る場合は、この線画版を差し替える形になります。プロンプトは `artwork-prompts.md` にあります

### 4.5 出品前に結パパさんに確認していただきたいこと(原文の確認)

調査環境からは以下に到達できず、**条文の原文を1件も読めていません**。数値・日付を含め、すべて検索結果のスニペット経由です。
出品前にご自身のブラウザで開いて、スクリーンショットを残してください。

1. メルカリガイド「禁止されている行為」と、生成AI・加工画像の注意点(2026年3月公開とされるもの)
