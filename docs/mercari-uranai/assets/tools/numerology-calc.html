数秘計算ツール

鑑定に使う数字をここで確定させてからAIに渡します。AIに計算そのものをさせると、 数字がズレたまま鑑定文が量産されます。計算過程を鑑定書に開示する以上、そこが間違っていると 誠実路線そのものが崩れます。

計算の決まり

  • ライフパス:生年月日の全桁を足し、1桁になるまで足す。途中で 11・22・33 が出たらそこで止める(マスターナンバー)
  • ディスティニー:名前のローマ字すべてを上の表で数値化して合計し、同じ規則で還元
  • ソウル:名前の母音(A・I・U・E・O)だけを合計して還元
  • パーソナルイヤー:生まれた月日の各桁 + 鑑定する年の各桁を合計して還元(詳細鑑定の「今年のテーマ」に使用)

入力はこの画面の中だけで処理され、どこにも送信されません。通信は発生しません。
